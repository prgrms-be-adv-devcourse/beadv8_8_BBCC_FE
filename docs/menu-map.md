# 메뉴 안내

기능마다 어느 메뉴에서, 무엇을 차례로 눌러 들어가는지 정리한 문서다. 메뉴를 더하거나 빼면 이 문서를 같이 고친다.

- 「들어가는 길」은 그 영역의 첫 화면에서 누르는 순서다. `→`는 다음에 누르는 것을 뜻한다
- 주소는 `src/shared/config/routes.ts`의 `paths`가 원본이다
- 메뉴는 아래 파일이 원본이다

| 메뉴                | 파일                                         |
| ------------------- | -------------------------------------------- |
| 시연 막대           | `src/widgets/demo-bar/ui/DemoBar.tsx`        |
| 쇼핑 머리말         | `src/widgets/shop-header/ui/ShopHeader.tsx`  |
| 마이페이지 메뉴     | `src/widgets/my-page-menu/ui/MyPageMenu.tsx` |
| 자녀 화면 머리말    | `src/app/layouts/ChildLayout.tsx`            |
| 판매자 센터 메뉴    | `src/app/layouts/CenterLayout.tsx`           |
| 관리자 메뉴         | `src/app/layouts/AdminLayout.tsx`            |
| 시연 콘솔 단계 메뉴 | `src/widgets/demo-step-bar/config/steps.ts`  |

## 1. 영역에 들어가는 길

영역은 다섯 개다. 시연 막대는 모든 영역 맨 위의 검은 막대다.

| 영역        | 첫 화면 주소    | 들어가는 길                                                                                                                                         |
| ----------- | --------------- | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| 쇼핑        | `/`             | 사이트 주소로 접속 / 시연 막대 「쇼핑」 / 판매자 센터 · 관리자 머리말의 쇼핑 링크                                                                   |
| 판매자 센터 | `/center`       | 시연 막대 「판매자 센터」 / 쇼핑 머리말 「판매자센터」(넓은 화면) / 쇼핑 머리말 「마이페이지」 → 메뉴 「판매자 센터」(판매자일 때) / 주소 `/center` |
| 판매자 신청 | `/center/apply` | 쇼핑 머리말 「마이페이지」 → 메뉴 「판매자 신청」(판매자가 아닐 때) / 쇼핑 바닥글 「판매자 입점」 / 판매자 센터 메뉴 「판매자 신청」                |
| 관리자      | `/admin`        | 시연 막대 「관리자」 / 주소 `/admin` → 관리자 계정으로 로그인                                                                                       |
| 시연 콘솔   | `/console`      | 시연 막대 「시연 콘솔」 / 주소 `/console`                                                                                                           |
| 자녀        | `/child`        | 시연 막대 「자녀」 / 로그인 화면의 자녀 화면 링크 / 주소 `/child`                                                                                   |

- 시연 막대는 빌드 값 `VITE_DEMO_ROLE_SWITCH`가 `false`인 배포에서는 나오지 않는다. 그 배포에서 관리자 · 자녀 화면은 주소를 직접 넣어 들어간다
- 관리자 화면은 보호자 · 판매자 로그인과 별개로 관리자 계정으로 로그인해야 열린다
- 관리자 메뉴 「설정」에서 시연 기능을 켜면 그 브라우저에서만 시연 막대가 다시 나온다

## 2. 쇼핑 (보호자)

첫 화면은 홈(`/`)이다. 머리말은 쇼핑의 모든 화면 위에 있다.

### 머리말에서 바로 가는 화면

| 화면           | 주소             | 들어가는 길                       | 비고                                |
| -------------- | ---------------- | --------------------------------- | ----------------------------------- |
| 홈             | `/`              | 머리말 로고                       |                                     |
| 검색 결과      | `/?q=검색어`     | 머리말 검색 칸에 입력 → 검색 버튼 | 홈의 상품 목록이 검색 결과로 바뀐다 |
| 판매자 센터 홈 | `/center`        | 머리말 「판매자센터」             | 휴대폰 폭에서는 나오지 않는다       |
| 알림함         | `/notifications` | 머리말 「알림」                   | 안 읽은 개수 표시                   |
| 내 찜          | `/my/favorites`  | 머리말 「찜」                     |                                     |
| 장바구니       | `/cart`          | 머리말 「장바구니」               | 담은 개수 표시                      |
| 마이페이지 홈  | `/my`            | 머리말 「마이페이지」             |                                     |
| 로그인         | `/login`         | 머리말 「로그인/회원가입」        | 로그인하면 「로그아웃」으로 바뀐다  |

알림함 · 찜 · 장바구니 · 마이페이지는 로그인하지 않았으면 로그인 화면으로 먼저 간다.

### 마이페이지 메뉴로 가는 화면

마이페이지 메뉴는 마이페이지 화면의 왼쪽(휴대폰은 화면 아래)에 있다.

| 화면                        | 주소               | 들어가는 길                                  |
| --------------------------- | ------------------ | -------------------------------------------- |
| 주문 내역                   | `/orders`          | 머리말 「마이페이지」 → 메뉴 「주문 내역」   |
| 장바구니                    | `/cart`            | 머리말 「마이페이지」 → 메뉴 「장바구니」    |
| 내 리뷰                     | `/my/reviews`      | 머리말 「마이페이지」 → 메뉴 「내 리뷰」     |
| 내 찜                       | `/my/favorites`    | 머리말 「마이페이지」 → 메뉴 「내 찜」       |
| 받은 조르기                 | `/my/wishes`       | 머리말 「마이페이지」 → 메뉴 「받은 조르기」 |
| 자녀 프로필(자녀 목록)      | `/my/children`     | 머리말 「마이페이지」 → 메뉴 「자녀 프로필」 |
| 자녀 등록                   | `/my/children/new` | 머리말 「마이페이지」 → 메뉴 「자녀 등록」   |
| 예치금                      | `/my/wallet`       | 머리말 「마이페이지」 → 메뉴 「예치금」      |
| 배송지 관리                 | `/my/addresses`    | 머리말 「마이페이지」 → 메뉴 「배송지 관리」 |
| 내 정보                     | `/my/profile`      | 머리말 「마이페이지」 → 메뉴 「내 정보」     |
| 판매자 센터 홈 (판매자)     | `/center`          | 머리말 「마이페이지」 → 메뉴 「판매자 센터」 |
| 판매자 신청 (판매자가 아님) | `/center/apply`    | 머리말 「마이페이지」 → 메뉴 「판매자 신청」 |

### 메뉴에 없고 다른 화면에서 들어가는 화면

| 화면                  | 주소                                  | 들어가는 길                                                                             |
| --------------------- | ------------------------------------- | --------------------------------------------------------------------------------------- |
| 상품 상세             | `/products/:상품`                     | 홈 → 상품 칸 (맞춤 목록 · 내 찜 · 장바구니 · 주문 상세의 상품에서도 같다)               |
| 옵션 고르고 담기 팝업 | (주소 없음)                           | 홈 → 상품 칸의 담기 버튼                                                                |
| 자녀 맞춤 목록        | `/recommended/:자녀`                  | 홈 → 맞춤 영역 「더보기」 (자녀가 있는 보호자에게만 맞춤 영역이 나온다)                 |
| 주문 상세             | `/orders/:주문`                       | 머리말 「마이페이지」 → 메뉴 「주문 내역」 → 주문 줄                                    |
| 자녀 상세             | `/my/children/:자녀`                  | 머리말 「마이페이지」 → 메뉴 「자녀 프로필」 → 자녀 줄 (마이페이지 홈의 자녀 줄도 같다) |
| 자녀별 받은 조르기    | `/my/children/:자녀/wishes`           | 머리말 「마이페이지」 → 메뉴 「받은 조르기」 → 자녀 고르기 (자녀 상세에서도 간다)       |
| 조르기 상세           | `/my/children/:자녀/wishes/:요청`     | 머리말 「마이페이지」 → 메뉴 「받은 조르기」 → 조르기 줄                                |
| 리뷰 쓰기             | `/my/reviews/new?orderItemId=`        | 머리말 「마이페이지」 → 메뉴 「내 리뷰」 → 리뷰를 기다리는 상품 (주문 상세에서도 간다)  |
| 예치금 이용 내역      | `/my/wallet/history`                  | 머리말 「마이페이지」 → 메뉴 「예치금」 → 이용 내역 링크                                |
| 예치금 충전           | `/my/wallet/charge`                   | 머리말 「마이페이지」 → 메뉴 「예치금」 → 충전 링크                                     |
| 충전 결과             | `/my/wallet/charge/success` · `/fail` | 예치금 충전 → 토스 결제를 마치면 돌아온다                                               |

## 3. 자녀 (`/child`)

첫 화면은 자녀 프로필이다. 메뉴는 자녀 화면 머리말에 모두 있다.

| 화면                | 주소                    | 들어가는 길                    |
| ------------------- | ----------------------- | ------------------------------ |
| 자녀 프로필         | `/child`                | 머리말 로고 또는 「내 프로필」 |
| 상품 목록           | `/child/products`       | 머리말 「상품」                |
| 상품 상세           | `/child/products/:상품` | 머리말 「상품」 → 상품 칸      |
| 자녀 장바구니       | `/child/cart`           | 머리말 「내 장바구니」         |
| 조른 상품           | `/child/wishes`         | 머리말 「내 조르기」           |
| 보호자가 사 준 상품 | `/child/purchases`      | 머리말 「나를 위해 산 것」     |
| 알림함              | `/child/notifications`  | 머리말 「알림」                |

## 4. 판매자 센터 (`/center`)

첫 화면은 판매자 센터 홈이다. 메뉴는 왼쪽(휴대폰은 위)에 있다.

| 화면               | 주소                        | 들어가는 길                    |
| ------------------ | --------------------------- | ------------------------------ |
| 판매자 센터 홈     | `/center`                   | 메뉴 「홈」                    |
| 내 상품 목록       | `/center/products`          | 메뉴 「상품 관리」             |
| 상품 상세          | `/center/products/:상품`    | 메뉴 「상품 관리」 → 상품 줄   |
| 상품 등록          | `/center/products/new`      | 메뉴 「상품 등록」             |
| 판매 주문 목록     | `/center/orders`            | 메뉴 「주문 · 배송」           |
| 판매 주문 상세     | `/center/orders/:주문`      | 메뉴 「주문 · 배송」 → 주문 줄 |
| 정산 예정 · 정산서 | `/center/settlements`       | 메뉴 「정산」                  |
| 정산서 상세        | `/center/settlements/:정산` | 메뉴 「정산」 → 정산서 줄      |
| 상점 정보          | `/center/store`             | 메뉴 「상점 정보」             |
| 판매자 신청        | `/center/apply`             | 메뉴 「판매자 신청」           |

## 5. 관리자 (`/admin`)

첫 화면은 대시보드다. 관리자 계정으로 로그인한 뒤 왼쪽 메뉴(휴대폰은 위)로 간다.

| 운영     | 멈춘 주문 · 처리 대기             | `/admin/order-ops`                         | 메뉴 「주문 운영」                       |

| 상품     | 상품 목록                         | `/admin/products`                          | 메뉴 「상품 관리」                       |

## 6. 시연 콘솔 (`/console`)

| ---- | ---------------- | ------------------------------------ | --------------------------------------- | ------ |
