# 메뉴 안내

기능마다 어느 메뉴에서 들어가는지 정리한 문서다. 메뉴를 더하거나 빼면 이 문서를 같이 고친다.

- 주소는 `src/shared/config/routes.ts`의 `paths`가 원본이다
- 메뉴는 아래 파일이 원본이다

| 메뉴                | 파일                                         |
| ------------------- | -------------------------------------------- |
| 시연 막대           | `src/widgets/demo-bar/ui/DemoBar.tsx`        |
| 쇼핑 머리말         | `src/widgets/shop-header/ui/ShopHeader.tsx`  |
| 마이페이지 메뉴     | `src/widgets/my-page-menu/ui/MyPageMenu.tsx` |
| 자녀 화면 머리말    | `src/app/layouts/ChildLayout.tsx`            |
| 판매자 센터 메뉴    | `src/app/layouts/CenterLayout.tsx`           |
| 관리자 메뉴         | `src/app/layouts/AdminLayout.tsx`            |
| 시연 콘솔 단계 메뉴 | `src/widgets/demo-step-bar/config/steps.ts`  |

## 1. 영역 사이를 오가는 길

영역은 다섯 개다: 쇼핑(`/`) · 판매자 센터(`/center`) · 관리자(`/admin`) · 시연 콘솔(`/console`) · 자녀(`/child`).

| 길                                      | 어디에 있나                          | 갈 수 있는 영역                              |
| --------------------------------------- | ------------------------------------ | -------------------------------------------- |
| 시연 막대의 영역 전환                   | 모든 영역 맨 위                      | 다섯 영역 모두                               |
| 머리말 「판매자센터」                   | 쇼핑 머리말 (넓은 화면에서만)        | 판매자 센터                                  |
| 마이페이지 메뉴 「판매」 묶음           | 마이페이지 왼쪽 메뉴 (휴대폰은 아래) | 판매자면 판매자 센터, 아니면 판매자 신청     |
| 바닥글 「판매자 입점」                  | 쇼핑 바닥글                          | 판매자 신청                                  |
| 로그인 화면의 자녀 화면 링크            | 로그인 화면                          | 자녀                                         |
| 판매자 센터 · 관리자 머리말의 쇼핑 링크 | 각 영역 머리말                       | 쇼핑                                         |
| 주소 직접 입력                          |                                      | `/admin` · `/center` · `/console` · `/child` |

- 시연 막대는 빌드 값 `VITE_DEMO_ROLE_SWITCH`가 `false`인 배포에서는 나오지 않는다. 그 배포에서 관리자 화면은 주소 `/admin`으로만 들어간다
- 관리자 화면은 관리자 계정으로 따로 로그인해야 열린다
- 관리자 「설정」에서 시연 기능을 켜면 그 브라우저에서만 시연 막대가 다시 나온다

## 2. 쇼핑 (보호자)

### 머리말

| 메뉴       | 화면            | 주소             | 비고                                |
| ---------- | --------------- | ---------------- | ----------------------------------- |
| 로고       | 홈              | `/`              |                                     |
| 검색 칸    | 홈의 검색 결과  | `/?q=검색어`     |                                     |
| 판매자센터 | 판매자 센터 홈  | `/center`        | 휴대폰 폭에서는 나오지 않는다       |
| 알림       | 알림함          | `/notifications` | 안 읽은 개수 표시                   |
| 찜         | 내 찜           | `/my/favorites`  |                                     |
| 장바구니   | 장바구니        | `/cart`          | 담은 개수 표시                      |
| 마이페이지 | 마이페이지 홈   | `/my`            |                                     |
| 로그인     | 로그인 (카카오) | `/login`         | 로그인하면 로그아웃 버튼으로 바뀐다 |

### 마이페이지 메뉴

| 묶음      | 메뉴        | 화면                           | 주소               |
| --------- | ----------- | ------------------------------ | ------------------ |
| 쇼핑      | 주문 내역   | 주문 내역                      | `/orders`          |
| 쇼핑      | 장바구니    | 장바구니                       | `/cart`            |
| 쇼핑      | 내 리뷰     | 쓴 리뷰 · 리뷰 기다리는 상품   | `/my/reviews`      |
| 쇼핑      | 내 찜       | 찜한 상품                      | `/my/favorites`    |
| 우리 아이 | 받은 조르기 | 자녀가 조른 상품               | `/my/wishes`       |
| 우리 아이 | 자녀 프로필 | 자녀 목록                      | `/my/children`     |
| 우리 아이 | 자녀 등록   | 자녀 등록                      | `/my/children/new` |
| 계정      | 예치금      | 예치금 잔액                    | `/my/wallet`       |
| 계정      | 배송지 관리 | 배송지                         | `/my/addresses`    |
| 계정      | 내 정보     | 회원 정보                      | `/my/profile`      |
| 판매      | 판매자 센터 | 판매자 센터 홈 (판매자일 때)   | `/center`          |
| 판매      | 판매자 신청 | 판매자 신청 (판매자가 아닐 때) | `/center/apply`    |

### 메뉴 없이 다른 화면에서 들어가는 화면

| 화면                  | 주소                                  | 들어가는 길                                              |
| --------------------- | ------------------------------------- | -------------------------------------------------------- |
| 상품 상세             | `/products/:상품`                     | 상품 칸을 누른다 (홈 · 맞춤 목록 · 찜 · 장바구니 · 주문) |
| 옵션 고르고 담기 팝업 | (주소 없음)                           | 상품 칸의 담기 버튼                                      |
| 자녀 맞춤 목록        | `/recommended/:자녀`                  | 홈 맞춤 영역의 「더보기」                                |
| 주문 상세             | `/orders/:주문`                       | 주문 내역의 주문 줄                                      |
| 자녀 상세             | `/my/children/:자녀`                  | 자녀 프로필 목록, 마이페이지 홈의 자녀 줄                |
| 자녀별 받은 조르기    | `/my/children/:자녀/wishes`           | 받은 조르기에서 자녀로 거르기, 자녀 상세                 |
| 조르기 상세           | `/my/children/:자녀/wishes/:요청`     | 받은 조르기의 줄                                         |
| 리뷰 쓰기             | `/my/reviews/new?orderItemId=`        | 내 리뷰 · 주문 상세의 리뷰 쓰기                          |
| 예치금 이용 내역      | `/my/wallet/history`                  | 예치금 화면                                              |
| 예치금 충전           | `/my/wallet/charge`                   | 예치금 화면의 충전                                       |
| 충전 결과             | `/my/wallet/charge/success` · `/fail` | 토스 결제 뒤 돌아온다                                    |

## 3. 자녀 (`/child`)

자녀 화면 머리말에 메뉴가 모두 있다.

| 메뉴             | 화면                | 주소                   |
| ---------------- | ------------------- | ---------------------- |
| 로고 · 내 프로필 | 자녀 프로필         | `/child`               |
| 상품             | 상품 목록           | `/child/products`      |
| 내 장바구니      | 자녀 장바구니       | `/child/cart`          |
| 내 조르기        | 조른 상품           | `/child/wishes`        |
| 나를 위해 산 것  | 보호자가 사 준 상품 | `/child/purchases`     |
| 알림             | 알림함              | `/child/notifications` |

상품 상세(`/child/products/:상품`)는 상품 목록에서 들어간다.

## 4. 판매자 센터 (`/center`)

| 묶음 | 메뉴        | 화면               | 주소                   |
| ---- | ----------- | ------------------ | ---------------------- |
| 판매 | 홈          | 판매자 센터 홈     | `/center`              |
| 판매 | 상품 관리   | 내 상품 목록       | `/center/products`     |
| 판매 | 상품 등록   | 상품 등록          | `/center/products/new` |
| 판매 | 주문 · 배송 | 판매 주문 목록     | `/center/orders`       |
| 판매 | 정산        | 정산 예정 · 정산서 | `/center/settlements`  |
| 상점 | 상점 정보   | 상호명 · 판매 상태 | `/center/store`        |
| 상점 | 판매자 신청 | 판매자 신청        | `/center/apply`        |

상품 상세(`/center/products/:상품`) · 주문 상세(`/center/orders/:주문`) · 정산서 상세(`/center/settlements/:정산`)는 각 목록에서 들어간다.

| 운영     | 설정             | 시연 데이터 · 시연 기능 켜고 끄기 | `/admin/settings`                  |
| 회원     | 회원 관리        | 회원 목록                         | `/admin/members`                   |
| 회원     | 판매자 신청 심사 | 판매자 신청 승인 · 반려           | `/admin/seller-applications`       |
| 커뮤니티 | 리뷰 검사        | 리뷰 숨김 · 다시 공개             | `/admin/community/reviews`         |
| 거래     | 전체 주문        | 주문 목록                         | `/admin/orders`                    |
| 거래     | 전체 결제        | 결제 목록                         | `/admin/payments`                  |
| 거래     | 정산             | 정산 실행                         | `/admin/settlements`               |
| 거래     | 지갑             | 회원 예치금 지갑                  | `/admin/wallets`                   |
| 상품     | 상품 관리        | 상품 목록                         | `/admin/products`                  |
| 상품     | 항목 · 목록 값   | 옵션 항목과 값                    | `/admin/catalog/attributes`        |

## 6. 시연 콘솔 (`/console`)

시연 기능을 켠 배포에서만 쓴다. 왼쪽 단계 메뉴가 시연 순서대로 놓여 있다.

| 단계 | 묶음          | 메뉴        | 주소                                 | 역할   |
| ---- | ------------- | ----------- | ------------------------------------ | ------ |
| ①    | 회원 · 자녀   | 자녀        | `/console/children`                  | 보호자 |
| ①    | 회원 · 자녀   | 배송지      | `/console/addresses`                 | 보호자 |
| ①    | 회원 · 자녀   | 내 정보     | `/console/profile`                   | 보호자 |
| ②    | 판매자 · 상품 | 판매자 신청 | `/console/seller/apply`              | 보호자 |
| ②    | 판매자 · 상품 | 승인        | `/console/admin/seller-applications` | 관리자 |
| ②    | 판매자 · 상품 | 상품 등록   | `/console/seller/products/new`       | 판매자 |
| ③    | 사이즈 추천   | 상품        | `/console/products`                  | 보호자 |
| ④    | 주문 · 결제   | 예치금      | `/console/wallet`                    | 보호자 |
| ④    | 주문 · 결제   | 장바구니    | `/console/cart`                      | 보호자 |
| ⑤    | 배송          | 판매 주문   | `/console/seller/orders`             | 판매자 |
| ⑥    | 구매확정      | 내 주문     | `/console/orders`                    | 보호자 |
| ⑦    | 정산          | 정산 실행   | `/console/admin/settlements`         | 관리자 |
| ⑦    | 정산          | 정산서      | `/console/seller/settlements`        | 판매자 |
| 관리 | 관리자 보완   | 회원        | `/console/admin/members`             | 관리자 |
| 관리 | 관리자 보완   | 상품        | `/console/admin/products`            | 관리자 |
| 관리 | 관리자 보완   | 주문        | `/console/admin/orders`              | 관리자 |
| 관리 | 관리자 보완   | 결제        | `/console/admin/payments`            | 관리자 |

- 흐름 확인(`/console/verify`)은 단계 메뉴와 콘솔 홈에서, 백엔드 연결 점검(`/console/connect`)은 콘솔 홈에서 들어간다
